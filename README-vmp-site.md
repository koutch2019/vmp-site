# VMP — Site institucional

Site institucional da VMP, com a seção de portfólio StudioFlow atualizada com o ativo visual extraído do APK.

## Conteúdo

- `vmp-site-atualizado.zip`: código-fonte completo do projeto React/Vite.
- O pacote inclui `client/public/studioflow-apk.png`.

## Desenvolvimento local

```bash
unzip vmp-site-atualizado.zip -d vmp-site
cd vmp-site
pnpm install
pnpm run dev
```
